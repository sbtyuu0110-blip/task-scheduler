# STEP 5: 「穴」の分析 —— 需要はあるのに既存商品が解決できていない場所

## 調査で判明した最重要パターン

複数の垂直市場（介護・障害福祉／建設／中小企業AI導入／一般事務）を横断して調べた結果、
**同一の構造が全市場で繰り返し出現した。**

> ### 空欄の「様式・ひな形」は、すでに無料で大量に存在する。
> ### 有料で解決されていないのは「自分の状況に合わせて、正しく、繰り返し中身を埋める」こと。

### 根拠（すべて一次〜準一次情報）

| 市場 | 無料で入手できるもの | 出典 |
|---|---|---|
| 障害福祉・介護 | 運営指導の事前提出様式、モデル様式集一式 | 静岡県、豊中市、吹田市の公式サイト |
| 中小企業のAI規程 | 生成AI利用ガイドラインのひな形 | 日本ディープラーニング協会(JDLA)が無償公開 |
| 建設業 | 安全書類（グリーンファイル）全24種の全建統一様式 | 業界標準様式として無償流通 |
| 一般事務 | 売上管理表・販売管理表等の各種Excel様式 | Microsoft公式、テンプレートBANK、ビズ研 等 |

**結論: 「テンプレートを売る」ビジネスは、無料の公式配布物と正面から競合する。**
これはスコア表で A7（汎用プロンプト集 62点）、A9（汎用チェックリスト 70点）、
A20（季節素材 66点）が下位に沈んだ主因である。

## 穴①：埋める作業と「間違えたときの金銭的損失」が放置されている

障害福祉分野の **個別支援計画未作成減算** が典型例。

- 未作成期間3ヶ月未満 → 基本報酬 **30%減算**
- 3ヶ月以上 → **50%減算**
- 令和元年時点で、この減算の適用を受けた事業所は **2割超**
- サビ管（サービス管理責任者）の退職・長期休暇で作成が止まると即発生
- 単なる減収に留まらず、報酬返還・指定更新への影響・信用低下に波及

つまり **「様式は無料で手に入るのに、正しく埋め続けられず、2割の事業所が実際に金を失っている」**。
これは典型的な「需要はあるのに解決されていない」状態である。

**ただし競合は既に存在する（重要な減点）**：かべなしクラウド（月額9,800円〜）、
カイポケ児発・放デイ（月額18,000円）、ポチパス等、障害福祉ソフトだけで15〜16製品。
「AI支援さん」「かんたん支援記録カンタン支援計画」（ChatGPT API利用）など生成AI機能も既に実装済み。
国保連請求との連携が強力な参入障壁になっている。

→ **示唆: 大手が押さえている「日次記録＋請求」ではなく、その周辺の未解決業務を狙う必要がある。**

## 穴②：中小企業は「AIを使いたい」が「社内で回す型」を持っていない

政府系機関の調査（一次情報）が、この穴を極めて明確に示している。

- 商工中金「中小企業の生成AI利用にかかる調査」(2026年1月調査/3月公表)
- 中小機構「中小企業のAI等の利活用に係る実態調査」(2026年3月)

| 指標 | 数値 |
|---|---|
| AI導入済み | **20.4%** |
| 導入検討中 | 18.6%（前向き計 39.0%） |
| **使用は個人の判断に任せている** | **64.9%** |
| 推進人材の不足 | 32.0% |
| ルール整備の遅れ | 25.1% |
| 部門別導入率：総務・管理 | 68.3% |
| 部門別導入率：製造・生産（現場） | 34.9% |

**読み解き**：
「AIを知らない」のではなく **「会社として回す仕組みがない」** のが実態。
65%が個人任せ＝統制も再現性もない状態。
一方で供給側は「ChatGPTの使い方」記事と汎用プロンプト集で飽和している（＝需要とズレている）。

さらに **供給側の価格が中小企業には高すぎる**：
- 集合型研修 15〜50万円 ／ オンライン研修 10〜30万円 ／ カスタム研修 30〜100万円
- 一方、無料のJDLAひな形は抽象的すぎて現場で回らない

→ **穴: 「無料の抽象ひな形」と「数十万円の研修」の間が空いている。**
  10人規模の会社が1週間で導入できる、具体的で動く資産（¥1〜5万円帯）が存在しない。

## 穴③：生成AIの日本語出力が、そのままでは業務品質に達しない

- 生成AIの多くは英語主軸に開発され、UIが日本語でも**敬語・言い回しが実務に耐えない**
- 「です・ます／謙譲語／尊敬語」の文脈依存の使い分けはAIにとって高難度タスク
- 「整っているのに伝わらない文章」をリライトする需要が実在（Udemy等に専用講座が成立）

→ **穴: 日本語ビジネス文書に特化した"出力を業務品質に固定する"仕組みには値段がつく。**
  これは英語圏プレイヤーが構造的に参入できない領域。

## 穴④：日本語圏では「製品」ではなく「役務」でしか売られていない領域がある

ココナラのNotion関連の実リスティング（実価格）：

| サービス | 価格 | 形態 |
|---|---|---|
| 採用ページテンプレ販売 (services/2818585) | ¥3,000 | 製品 |
| タスク管理Notionテンプレ (services/4058963) | ¥10,000 | 製品 |
| プロジェクト管理導入 (services/2750148) | ¥10,000 | 役務 |
| オーダーメイド作成 (services/1971432 他) | ¥5,000〜10,000 | **役務** |

対して英語圏Gumroadでは「Notion template for freelancers」で同質の**既製品**が即座に10件以上ヒット
（Freelancer OS / Freelance Dashboard / Notion Freelancer Pack / Solo Hustle System …）。

→ 日本語圏は既製品が薄い＝製品化の余地あり。
  **ただし日本のNotion利用者母数自体が小さく、天井が低い**点は正直に減点すべき（A2を92点に留めた理由）。

## 逆に「穴ではなかった」もの（罠）

調査の結果、**魅力的に見えるが避けるべき**と判断したもの。

| 候補 | なぜ罠か | 根拠 |
|---|---|---|
| ココナラ コンテンツマーケットで安価デジタル商品を量産 | **供給過剰＋価格崩壊** | 開始13ヶ月で46,122件。**58.5%が¥500**、**約74%が販売0件** |
| 汎用プロンプト集の販売 | 市場が消滅済み | 「100 ChatGPTプロンプト」系は無料で入手可能なため死亡 |
| AI生成物の量産販売 | **アカウント凍結リスク** | Gumroadでは AI生成物・プロンプトパック販売者の凍結事例が報告されている |
| 汎用デジタルプランナー（Etsy） | 差別化不能 | 2020年以降競合激増、SEO勝負に。個人の後発参入は不利 |
| Kindle「文字だけの本」量産 | 単価崩壊 | Kindle Unlimitedは**1ページ約0.4円**。100ページ読まれて約40円 |
| ブログアフィリエイト | 初売上が遅すぎる | 検索流入の立ち上げに数ヶ月〜年単位。3ヶ月縛りと相性最悪 |

## 穴の総合結論

> **売るべきものは「情報」でも「空の様式」でもなく、**
> **『特定の職種の、特定の書類を、自分のデータで、正しく埋め切る道具』である。**

この結論が、最終候補の選定基準になる。
