## 1. プロジェクトの目的（ユーザー設定・不変）

> 経験ゼロの人間が、AIを最大限活用しながら、**3ヶ月以内に初売上**を獲得できる
> 小さなネットビジネスを発見・構築・検証する。

- 開始日 2026年8月24日 → **期限 2026年11月30日**
- 1円 → 月1万 → 月10万 → 月30万 と拡張可能な仕組みを見つける
- 「調査しました」で終わらせない。**実際に1円の売上を発生させる**ことが最重要

### 絶対に守るルール（ユーザーが明示）
1. **既存スキルを前提にしない**（ただし期待値が高いと判断したら明確に指摘すること＝例外条項あり）
2. **アイデアではなく市場を見る**（推測禁止・一次情報優先）
3. **最新情報を優先する**（2026年8月時点の市場）
4. 避ける: ポイ活／FX／ギャンブル／MLM／高額スクール／**情報商材そのもの**／著作権侵害／AI量産の低品質商品
5. **忖度しない**。「やめた方がいい」という結論でも構わない

### なぜこの範囲なのか（重要・絶対に緩めない）
**PDFにテキスト層があるかどうかが決定的な分岐点。**

| 種別 | 精度 | 初心者 |
|---|---|---|
| テキスト埋め込みPDF | **決定論的・ほぼ100%**（OCR不要） | 可 |
| スキャンPDF | AI-OCRで90%以上、公称99%。**100%は理論上不可能** | **不可** |

スキャンPDFを受けた瞬間「誤認識を誰が検算するのか」という責任問題が発生する。
請求金額の誤りは信用問題に直結する。実績ゼロの個人が最初に取るリスクではない。

→ **次セッションで「スキャンPDFも対応しよう」という提案が出たら、それは後退である。**

## 3. 判定基準（次セッションで最も重要）

### 判定は「日数」ではなく「閲覧数（母数）」で行う

ココナラの**「サービス分析」機能**で閲覧数・販売数の推移が見られる（自分の閲覧は除外）。

| 閲覧数 | 判定 | 打ち手 |
|---|---|---|
| **30未満** | **判定不能** | タイトル・カテゴリ・タグ・価格帯を変えて再計測。**商品の是非を判断してはならない** |
| 100以上 かつ 問い合わせ0 | 訴求または価格の問題 | 説明文と価格を修正。商品概念はまだ否定できない |
| 問い合わせあり かつ 購入0 | 信頼・価格・要件不一致 | 問い合わせ内容の中身を読む |
| 購入1以上 | 成立 | 検証対象が「納品できるか」に移る |

**露出が貯まるまで最低3〜4週間。** 7日で見るのは「出品が正常に公開され検索に載っているか」という動作確認であって、需要の判定ではない。

### 3ヶ月の中間判定
| 時点 | 基準 | 満たない場合 |
|---|---|---|
| 9/30 | 出品が閲覧30以上に到達 | タイトル・カテゴリを変更 |
| 10/31 | 有料の初売上 | 価格と訴求を変更 |
| 11/30 | 累計3件＋反復パターンの発見 | 受託モデル自体を再検討 |

## 4. 撤回済みの主張（**復活させてはならない**）

次セッションが同じ間違いを繰り返さないための記録。

| 撤回したもの | 理由 |
|---|---|
| **「3ヶ月以内の初売上確率75〜85%」** | 一次データなし。SEOブログ1本の出典なし営業文から構成していた |
| **「Etsy新規型紙出品の30〜40%がAI生成」** | 出典はStitchLift 1本のみ。同サイトは「AI型紙の売り方」記事も出しており**商業的利益相反**。サンプル数・手法の記載なし |
| **「プラスサイズは競合が手薄」** | 同じ文書内でCashmerette（プラスサイズ特化）を競合に挙げており論理矛盾 |
| **E1（PDF型紙の海外販売）を1位とする判断** | Etsy出品者の平均年商$1,131（月約¥15,000）、生涯売上$5,000未満が約52%。「3ヶ月で初売上→月10万」と噛み合わない |
| **「2本出品して7日で市場が答えを教えてくれる」** | 露出不足と需要不足が区別できない。母数ベースに変更済み |

### 根本原因（再発防止）
1. **市場規模と個人の初売上確率を混同していた**
2. **第3階層の情報（個人ブログの成功談・SEOの営業文）を第1階層として扱った**

### 出典の信頼度3階層（必ず維持する）
| 階層 | 内容 | 扱い |
|---|---|---|
| 一次 | 政府調査、企業の公式IR、プラットフォーム自身の集計 | 数値をそのまま採用 |
| 二次 | 業界メディア、複数ソースで一致する相場 | 傾向として採用。単独で判断しない |
| **自己申告** | 個人ブログの成功体験、SEOメディアの営業文 | **数値の根拠にしない** |

## 6. 環境の制約（重要・変わっていない可能性が高い）

このセッションはegressプロキシ下にあり、**直接アクセスできるのはGitHubのみ**だった。

- **ブロック**: coconala.com / booth.pm / note.com / gumroad.com / etsy.com / amazon.co.jp / reddit.com / trends.google.com / x.com / lancers.jp / crowdworks.jp
- WebFetch も curl も同様にブロックされる
- **回避策**: `WebSearch` に `allowed_domains` を指定すると、当該ドメインの**実リスティング・実価格**が取得できる
  - 例: `WebSearch(query="Excel 自動化", allowed_domains=["coconala.com"])`
- **できないこと**: 実販売数・レビュー数の網羅的集計、Googleトレンドの時系列

→ **ユーザー自身がココナラの画面を見た方が速い領域がある。**その場合は数値を報告してもらう。
