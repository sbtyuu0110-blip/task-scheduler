> 経験ゼロの人間が、AIを最大限活用しながら、**3ヶ月以内に初売上**を獲得できる

## 2. 商品（確定・変更しない）

**請求書PDF → Excel／スプレッドシート転記の自動化。**

| 項目 | 内容 |
|---|---|
| 対象 | **テキスト層のあるPDF のみ**／1発行元・1書式 |
| 中心機能 | **検算。合わなければ書き込まず、行の名前と差額を出して止まる** |
| 価格 | ¥9,500（初回設定費。枚数ではなく仕組み1つ分） |
| 納期 | 7日 |

### 対象外（緩めない）
スキャン・写真・手書き／発行元ごとに書式が違うものの混在／会計ソフト直接連携／
転記結果の正当性の保証／要件定義から入る案件／長期常駐

**理由：AI-OCRは公称99%だが100%は理論上不可能。** 誤認識を検算できない。
請求金額の誤りは信用問題に直結し、実績ゼロの個人が最初に取るリスクではない。

→ **「スキャンPDFも対応しよう」という提案が出たら、それは後退である。**

### 実装（完成済み・実測確認済み）
`tools/invoice_to_excel/` — 5つの安全機構すべて動作確認済み。

| 機構 | 動作 |
|---|---|
| テキスト層の検出 | 50字未満はスキャン疑いとして拒否 |
| 明細の検算 | 各行 `数量×単価 = 金額`（差額つき） |
| 合計の突合 | `明細合計=小計` かつ `小計+税=合計金額`（差額つき） |
| 未知の行の検知 | 明細欄に金額があるのに読めなかった行を**名指しで報告** |
| 二重計上の防止 | 転記済みの請求書番号は再転記しない |

**書式が毎月変わる件も実測済み**：新項目の追加・行数の変化は通る。
行の作りが違う項目（数量・単価のない調整額など）は止まってその行を名指しする。

> **9月中に、市場への提示を3経路×各1回完了する**（出品／プロフィール／ランサーズ）

### 9/30 に数える3つ
1. ココナラ出品の**閲覧数**
2. プロフィール経由の**スカウト・問い合わせ数**
3. 実際に**応募できた件数**

**どれか1つでも動けば、そこを太くする。全部0なら、商品ではなく販路の前提を疑う。**

### ココナラ出品の判定

| 閲覧数 | 判定 |
|---|---|
| **30未満** | **判定不能。** タイトル・タグ・カテゴリを変えて再計測。**商品の是非を判断してはならない** |
| 100以上 かつ 問い合わせ0 | 訴求または価格の問題。商品概念はまだ否定できない |
| 問い合わせあり かつ 購入0 | 実績不足・価格・要件不一致。中身を読む |
| 購入1以上 | **成立。**検証対象が「納品できるか」に移る |

**閲覧が伸びないことを理由に商品を否定しない。** これは3経路のうち1本である。

## 7. 撤回済みの主張（**復活させてはならない**）

| 撤回したもの | 理由 |
|---|---|
| 「3ヶ月以内の初売上確率75〜85%」 | 一次データなし。出典のない営業文から構成していた |
| 「Etsy新規型紙出品の30〜40%がAI生成」 | 出典1本のみ。同サイトは商業的利益相反あり |
| E1（PDF型紙の海外販売）を1位とする判断 | Etsy出品者の平均年商$1,131。目的と噛み合わない |
| 「2本出品して7日で市場が答えを教えてくれる」 | 露出不足と需要不足が区別できない |
| **「出品して閲覧数を貯めて判定する」を主軸にすること** | 律速が露出で制御不能（8/26撤回）。**ただし応募型の流量も制御できず、出品を「ほぼ無価値」と扱ったのは行き過ぎだった。両方走らせるのが正解**（8/29修正） |
| **候補を並べてスコアを付けるランキング表** | 導出過程のない数値は根拠の無さを隠す（8/26明文化） |
| **カテゴリ名から領域を推定すること** | 「AI-BPO（AI活用の業務改善）」の中身はSNS運用代行とオンライン秘書だった（8/29実測） |

### 根本原因（再発防止）
1. 市場規模と個人の初売上確率を混同していた
2. 第3階層の情報を第1階層として扱った
3. **商品定義の狭さを、探索範囲にも持ち込んでいた**（8/28）

#### 顔写真の撮り方（効く順）
1. **カメラから1.5〜2m離れてズームで寄る**（近接はレンズ歪みで顔が歪む）
2. **インカメではなくアウトカメラ**
3. **曇りの日の日中、窓に向かって立つ**（蛍光灯の真下・逆光はNG）
4. **選ぶときは32pxに縮小して選ぶ**（大画面で選ぶと失敗する）
- 背景は白い壁、壁から1m離れる／カメラは目の高さ／襟のある無地のシャツ／30枚以上撮る
- **加工はしない**（この商品の売りは正直さ。加工写真は矛盾する）

### 次セッションのAIの役割（状況別）

**A. まだ写真・プロフィールが済んでいない**
