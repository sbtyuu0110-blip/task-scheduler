# メモ受け箱

書いた瞬間に放り込み、整理は後でAIにまとめて任せるための仕組み。

- 入力：iPhone（背面タップ → ショートカット）、将来は Surface（ペンのボタン → 常駐アプリ）
- 受け口：Google Apps Script のウェブアプリ（`gas/Code.gs`）
- 保存先：Googleスプレッドシートの「メモ」シート（手書き画像は Drive の `受け箱/手書き/年-月/`）

## 「メモ」シートの列

| 列 | 内容 |
|---|---|
| A 日時 | 入力した時刻（端末の時刻） |
| B メモ | 本文（手書きは AI が読み取った文章。読む前は「（手書き・未読）」） |
| C 分類 | AI が入れる |
| D 状態 | 未整理 → 整理済み／要確認／除外 |
| E メモID | 二重登録の防止と画像の紐付けに使う |
| F 端末 | 合言葉から判定した端末名 |
| G 画像 | 手書き画像へのリンク |
| H AIメモ | AI の要約や「要確認」の理由 |
| I 受信日時 | シートに届いた時刻 |

## 受け口の返事

`OK` で始まる返事（`OK` / `OK-DUP` / `OK-EMPTY`）なら、端末は控えを消してよい。
それ以外（`NG` / `BADREQ` / `TOOBIG` / `ERROR`）なら控えを残して後で再送する。
ただし `BADREQ` / `TOOBIG` は何度送っても同じなので、Surface のアプリは「送れなかった」フォルダに移して後ろのメモを先に送る（iPhone は未送信フォルダに残したまま、次のファイルへ進む）。
