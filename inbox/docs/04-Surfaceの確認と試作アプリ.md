# 手順書4：Surface の確認と試作アプリ QuickInk

QuickInk は、Surface で「ペンのボタン → 白紙 → 書く → 指で上にフリック」を試すための試作アプリです。
PCの起動時から裏で待機していて、合図を受けると隠してあった白紙を出すだけなので、毎回の起動の待ち時間がありません。
書いた部分は画像として「送信待ち」に保存され、裏で受け口に送られます（オフラインでも消えません）。

この手順書は3部です。
- **A. 購入前（店頭の展示機で）**：5分
- **B. 届いた日**：30分
- **C. 速さの測定**：30分

---

## A. 購入前に店頭の展示機で見ておくこと

**操作**
1. 展示機で「設定」→「Bluetooth とデバイス」→「ペンと Windows Ink」を開く
2. 「ペンのショートカット」（トップボタンの割り当て）の「シングルクリック」の選択肢を開く
3. 選択肢をスマホで撮影する

**見るポイント**：「アプリを開く」のように、**好きなアプリを選べる項目があるか**。あれば、QuickInk をペンのボタンに割り当てる一番簡単な方法が使えます。なくても、B の手順で別の方法を試します。

ついでに、同じ画面の「手書き」の設定で日本語の手書き入力を試し、書き心地を見ておくと参考になります。

## B. 届いた日

### B-1. 先に確認すること

**操作**
1. 「設定」→「Windows Update」で更新をすべて済ませる（ペンの機能が新しくなっていることがあります）
2. ペンをペアリングする（ペンのトップボタンを5〜7秒長押しし、ライトが白く点滅したら「設定」→「Bluetooth とデバイス」→「デバイスの追加」）
3. 「Windows セキュリティ」→「アプリとブラウザー コントロール」→「スマート アプリ コントロール」の状態を見る

**こうなればOK**：ペンで書け、トップボタンを押すと何か（Whiteboard など）が開く。スマート アプリ コントロールが「オン」「評価」「オフ」のどれかを控えた。

> QuickInk は自作のため署名がなく、スマート アプリ コントロールが「オン」だと実行できません。その場合はオフに切り替えます（最近の Windows ではあとからオンに戻せます）。

### B-2. QuickInk を入れる

**操作**
1. Surface のブラウザで GitHub にログインし、`sbtyuu0110-blip/task-scheduler` リポジトリの「Actions」タブを開く
2. 「QuickInk build」の一番上（最新）の実行を開き、下の「Artifacts」から **`QuickInk-win-arm64`** をダウンロード（`win-x64` は Surface 以外のPC用）
3. zip を開いて `QuickInk.exe` を取り出し、`ドキュメント` の中に `QuickInk` フォルダを作って入れる（あとで場所を変えるとペンの割り当てが外れるので、置き場所を決めてから）
4. `QuickInk.exe` をダブルクリック
   - 「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」
5. 白紙が全画面で出る。ペンで何か書き、`Esc` で閉じる

**こうなればOK**：タスクバー右下（「^」の中のこともある）に QuickInk のアイコンがある。

### B-3. 送り先を設定する

**操作**
1. 右下の QuickInk のアイコンを右クリック →「設定ファイルを開く」→ メモ帳が開く
2. `url` の値を受け口のURLに、`token` の値を **Surface の合言葉**（手順書1で表示された2つ目）に書き換える。`"` は消さない
   ```
   {
     "url": "https://script.google.com/macros/s/……/exec",
     "token": "Surfaceの合言葉"
   }
   ```
3. 上書き保存して閉じる
4. アイコンを右クリック →「Windowsの起動時に裏で起動」にチェックを入れる

**こうなればOK**：アイコンにマウスを乗せたとき「（未設定）」と出ない。

### B-4. 1件送ってみる

**操作**
1. アイコンをダブルクリック → 白紙にペンで「テスト」と書く
2. 指で画面を下から上に素早くなぞる（フリック）。または画面下の帯をペンで上に引き上げる。または `Ctrl+Enter`
3. 白紙が消える

**こうなればOK**：数秒〜1分で「メモ」シートに「（手書き・未読）」の行が増え、G列の「画像」を開くと書いた文字が見える。届かない場合は、アイコン →「記録フォルダを開く」→「送信.csv」の「結果」を見る（手順書1の「困ったとき」と同じ意味です）。

### B-5. ペンのボタンで白紙を出す方法を探す

QuickInk は、考えられる4つの合図を同時に待ち受けて、どれで開いたかを記録します。

**操作**
1. まず、そのままペンのトップボタンを1回押す
2. 白紙が出なければ、「設定」→「ペンと Windows Ink」→ ショートカットボタンの割り当てを順に試す
   - 「アプリを開く」のような項目があれば、`ドキュメント\QuickInk\QuickInk.exe` を選ぶ
   - 「なし」（何もしない）にする
   - 「アプリによるショートカットボタンの動作の上書きを許可」をオンにする
3. 試すたびにトップボタンを押し、白紙が出たかを見る
4. アイコン →「記録フォルダを開く」→「診断.txt」と「速度.csv」を開く

**こうなればOK**：「速度.csv」の「きっかけ」に、白紙が出たときの経路（例：`ペンボタン1回（PenButtonListener）`、`exeの起動（ペンの設定など）`）が記録されている。

「診断.txt」の1行目に `アプリの種類=Arm64` とあれば、Snapdragon 向けに直接動いています。

**Claude に送ってほしいもの**：「診断.txt」と「速度.csv」の中身、どの設定のときに白紙が出たか。

## C. 速さを測る

### C-1. アプリの記録で測る（手軽）

**操作**
1. 白紙を出しては `Esc` で閉じる、を10回くり返す（ペンのボタンで出せればペンで、無理なら `Ctrl+Alt+M` で）
2. 30分ほど放っておいてから1回、スリープを解除した直後に1回、同じく出す
3. 「速度.csv」を開く

「ミリ秒」の列が、合図を受けてから白紙が書ける状態になるまでの時間です（1000ミリ秒＝1秒）。目標は中央値300ミリ秒以内。

### C-2. スロー動画で測る（正確。ペン自体の反応時間も含む）

**操作**
1. iPhone のカメラをスローモーションにし、Surface の画面とペンのボタンを押す指が両方映るように構える
2. ボタンを押す → 白紙が出る、を10回撮る（数秒ずつ空ける）
3. 写真アプリで動画を開き、「編集」で少しずつ送りながら、「ボタンを押し込んだコマ」から「白紙が出たコマ」までのコマ数を数える
4. 秒 ＝ コマ数 ÷ 240

比較のため、ペンのボタンを元の割り当て（Whiteboard など）に戻して、同じように測ってください。

### C-3. 書き心地

同じ文（例：「明日10時にA社へ電話」）を、QuickInk、Whiteboard、OneNote でそれぞれ5回書き、書き心地を5段階で付けてください。

**Claude に送ってほしいもの**：C-1 の「速度.csv」、C-2 のコマ数、C-3 の点数。これをもとに、このまま QuickInk を育てるか、別の作り方と比べるかを決めます。

## 試作でまだできないこと

- 送った直後の「取り消し」（今は送信待ちフォルダから手で消せば取り消せます。送信は数秒後）
- キーボードでの文字入力
- 書いた後のページ送り（1画面に収まる分だけ）
- アイコンが Windows 標準のもの
