# 手順書1：受け口（Apps Script）を v2 に置き換える

所要時間：20分ほど。今の受け口のURLは変わりません。今のショートカットも、作業中ずっと使えます。

各手順は「操作」「こうなればOK」の順に書いています。うまくいかないときは最後の「困ったとき」を見てください。

---

## 1. 今のコードを控える

**操作**
1. メモ用のスプレッドシートを開く
2. メニューの「拡張機能」→「Apps Script」を開く
3. 今のコードを全部選んでコピーし、iPhoneのメモアプリなどに貼って保存する
4. 1行目の `const TOKEN = '……';` の `'` と `'` の間の文字（今の合言葉）を、別に書き留める

**こうなればOK**：今のコードと今の合言葉が手元に残っている。

---

## 2. 新しいコードを貼る

**操作**
1. エディタの中身を全部消す
2. リポジトリの `inbox/gas/Code.gs` の中身を全部コピーして貼る
3. 上の保存ボタン（フロッピーの絵）を押す

**こうなればOK**：赤いエラー表示が出ずに保存できる。

---

## 3. タイムゾーンを東京にする

**操作**
1. 左側の歯車（プロジェクトの設定）を押す
2. 「タイムゾーン」を「(GMT+09:00) 日本標準時 - 東京」にする

**こうなればOK**：タイムゾーンが東京になっている。

---

## 4. setup を実行して合言葉を作る

**操作**
1. 左側の「<>」（エディタ）に戻る
2. 上の関数の選択欄で `setup` を選び、「実行」を押す
3. 「承認が必要です」と出たら、次のように進む
   - 「権限を確認」→ 自分のGoogleアカウントを選ぶ
   - 「このアプリは Google で確認されていません」と出たら、「詳細」→「（プロジェクト名）に移動」
   - 「許可」を押す（スプレッドシートとDriveの権限。Driveは手書き画像の保存に使います）
4. 画面下の「実行ログ」に、合言葉が2行表示される
   - `iPhone の合言葉: ……（64文字）`
   - `Surface の合言葉: ……（64文字）`

**こうなればOK**：合言葉が2つ表示され、スプレッドシートに「ログ」シートができ、「メモ」シートの見出しが「日時〜受信日時」の9列になっている。

> 合言葉はあとで「プロジェクトの設定」→「スクリプト プロパティ」でいつでも見られます。メモやスクリーンショットで人に渡さないでください。

---

## 5. 今のショートカットを使い続けられるようにする

新しいコードでは、合言葉をコードではなく「スクリプト プロパティ」に置きます。今のショートカットが送ってくる今の合言葉も、移行が終わるまで受け付けるようにします。

**操作**
1. 歯車（プロジェクトの設定）→ 一番下の「スクリプト プロパティ」→「スクリプト プロパティを追加」
2. プロパティ：`TOKEN_iPhoneOld`
3. 値：手順1で書き留めた今の合言葉
4. 「スクリプト プロパティを保存」を押す

**こうなればOK**：一覧に `TOKEN_iPhone`、`TOKEN_Surface`、`TOKEN_iPhoneOld` の3つが並んでいる。

---

## 6. 動作を確認する

**操作**
1. エディタに戻り、関数の選択欄で `testPost` を選んで「実行」
2. 実行ログを見る

**こうなればOK**
- 実行ログに `結果: OK` と `2回目: OK-DUP` が出る（同じメモを2回送っても1行しか入らない、という確認です）
- 「メモ」シートの一番下に `- テスト送信（この行は消してOK）` が、**`#ERROR!` にならず文字のまま**入っている
- 「ログ」シートに2行記録されている

確認できたら、「メモ」シートのテスト行を行ごと削除してください。

---

## 7. ウェブアプリを更新する（URLを変えない方法）

**操作**
1. 右上の「デプロイ」→「デプロイを管理」
2. 今のデプロイを選び、右上の鉛筆（編集）を押す
3. 「バージョン」を「新バージョン」にする
4. 次の3つを確認する
   - 種類：ウェブアプリ
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
5. 「デプロイ」を押す

**こうなればOK**：表示されたウェブアプリのURLが、今ショートカットに入っているURLと同じ。

> 「新しいデプロイ」は押さないでください。URLが変わり、ショートカットから届かなくなります。

---

## 8. 今のショートカットで1件送ってみる

**操作**：いつもどおり背面タップでメモを1件送る。

**こうなればOK**：「メモ」シートに1行増え、F列（端末）が `iPhoneOld` になっている。

ここまでで手順書1は完了です。次は「手順書2：iPhoneショートカット v2」に進んでください。

---

## 困ったとき

| 症状 | 確認すること |
|---|---|
| ショートカットで送っても行が増えない | 「ログ」シートの最新行の「結果」を見る。`NG` なら合言葉が違う（手順5の値を確認）。ログ自体が増えていなければ、手順7が終わっていない |
| `ERROR` が記録される | 「ログ」シートの「備考」にエラーの内容が出ます。その文を Claude に貼ってください |
| `#ERROR!` の行ができる | 手順2で古いコードのままになっていないか確認 |
| 承認画面が出ない・途中で閉じた | もう一度 `setup` を実行する |
| 合言葉が漏れたかもしれない | エディタで `renewToken` の `const DEVICE = 'iPhone';` をその端末名にして実行。古い合言葉はすぐ使えなくなるので、ショートカットの合言葉も新しいものに替える |

## 移行が終わったら

手順書2の新しいショートカットに切り替えたら、手順5で追加した `TOKEN_iPhoneOld` を削除してください（スクリプト プロパティの一覧で、その行のメニューから削除）。
