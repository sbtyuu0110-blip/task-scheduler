# 手順書2：iPhoneショートカット v2（未送信フォルダと再送）

所要時間：30分ほど。先に「手順書1」を終えてください。

v2 ではショートカットを2つにします。

| ショートカット | 役割 | 起動のしかた |
|---|---|---|
| **メモ** | 入力して、未送信フォルダに保存する | 背面ダブルタップ |
| **受け箱に送る** | 未送信フォルダの中身を全部送り、届いたものを消す | 「メモ」の最後に自動で実行＋決まった時刻に自動実行 |

メモは送る前に必ず未送信フォルダに保存されます。オフラインで送れなくても消えず、次の機会に送られます。

用意するもの：受け口のURL（今のショートカットに入っているもの）、手順書1で表示された **iPhone の合言葉**（64文字）。

> アクション名は日本語表示のものを書き、（ ）に英語名を添えています。ショートカットアプリのアクション検索で探してください。

---

## 1. 未送信フォルダを作る

**操作**
1. 「ファイル」アプリ →「ブラウズ」→「iCloud Drive」→「Shortcuts」フォルダを開く
2. 右上の「…」→「新規フォルダ」→ 名前を `未送信` にする

**こうなればOK**：iCloud Drive › Shortcuts の中に「未送信」フォルダがある。

---

## 2. 「受け箱に送る」を作る

**操作**：ショートカットアプリ →「＋」で新規作成し、名前を `受け箱に送る` にして、次のアクションを順に追加する。

1. **フォルダの内容を取得**（Get Contents of Folder）
   - フォルダ：iCloud Drive › Shortcuts › 未送信
2. **各項目を反復**（Repeat with Each）：入力は「フォルダの内容」
3. 反復の中に **URLの内容を取得**（Get Contents of URL）
   - URL：受け口のURL
   - 「▶」で詳細を開き、方法：`POST`
   - 本文を要求：`ファイル`、ファイル：`反復項目`
4. その下（反復の中）に **if**（If）
   - 条件：`URLの内容` が `次で始まる` `OK`
5. if の中に **ファイルを削除**（Delete Files）
   - 削除するもの：`反復項目`
   - 「▶」で詳細を開き、「削除前に確認」をオフ

完成形：
```
フォルダの内容を取得（未送信）
各項目を反復
    URLの内容を取得（POST・本文はファイル＝反復項目）
    もし URLの内容 が「OK」で始まるなら
        ファイルを削除（反復項目・確認なし）
    終了
反復の終了
```

**こうなればOK**：未送信フォルダが空の状態で実行すると、何も起きずに終わる。

---

## 3. 「メモ」を作り直す

今の背面タップ用ショートカットを開き、中のアクションを全部消してから、次を順に追加します（ショートカットの名前は変えないでおくと、背面タップの設定もそのまま使えます）。

1. **入力を要求**（Ask for Input）
   - 種類：テキスト、質問：`メモ`
   - **必ず一番上に置く**（入力欄を一番早く出すため）
2. **if**：`指定された入力` が `値がない`
   - if の中に **このショートカットを停止**（Stop This Shortcut）
3. **現在の日付**（Current Date）
4. **日付をフォーマット**（Format Date）
   - 日付：`現在の日付`、日付フォーマット：`ISO 8601`、「時刻を含める」をオン
5. **変数を設定**（Set Variable）：名前 `入力時刻`、値は上の「フォーマット済みの日付」
6. **日付をフォーマット**（Format Date）
   - 日付：`現在の日付`、日付フォーマット：`カスタム`、書式：`yyyyMMdd-HHmmss`
7. **乱数**（Random Number）：最小 `1000`、最大 `9999`
8. **テキスト**（Text）：`フォーマット済みの日付`-`乱数`-iP
   - 変数を2つ並べ、間に半角の `-` を入れ、最後に `-iP` と打つ（例：`20261103-153012-4821-iP` になる）
9. **変数を設定**：名前 `メモID`、値は上の「テキスト」
10. **辞書**（Dictionary）：「＋新規項目」で次の5つを追加（すべて種類は「テキスト」）

    | キー | 値 |
    |---|---|
    | `token` | iPhone の合言葉（64文字を貼る） |
    | `id` | 変数 `メモID` |
    | `createdAt` | 変数 `入力時刻` |
    | `type` | `text` |
    | `text` | `指定された入力` |

11. **テキスト**（Text）：中身は変数 `辞書` だけ
12. **名前を設定**（Set Name）：入力は上の「テキスト」、名前は `メモID`.json
13. **ファイルを保存**（Save File）
    - 入力：`名前を変更したアイテム`
    - 「保存先を尋ねる」をオフ
    - 保存先パス：`/未送信/`
    - 「上書き」はオフ
14. **ショートカットを実行**（Run Shortcut）：`受け箱に送る`

**こうなればOK**：背面タップの設定（設定 → アクセシビリティ → タッチ → 背面タップ → ダブルタップ）が「メモ」のままになっている。

> 合言葉は未送信のファイルの中にも書かれます（あなたの iCloud Drive の中だけです）。ショートカットやこのファイルを人に共有しないでください。

---

## 4. 動作を確認する

### 確認1：ふつうに送る
1. 背面ダブルタップ →「- テスト1」と入力 → 完了

**こうなればOK**：数秒以内に「メモ」シートに1行増え、F列が `iPhone`、E列にメモIDが入っている。「未送信」フォルダは空。

### 確認2：オフラインで送る（いちばん大事な確認）
1. コントロールセンターで機内モードをオンにする
2. 背面ダブルタップ →「テスト2」と入力 → 完了
3. エラーが表示されて止まる（正常です）
4. 「ファイル」アプリで「未送信」フォルダを開く → ファイルが1つ残っている。開くと `{"token":…,"text":"テスト2"…}` のような中身が見える
5. 機内モードをオフにして、ショートカット「受け箱に送る」を実行する

**こうなればOK**：「テスト2」がシートに入り、A列の時刻が**機内モード中に入力した時刻**になっている。「未送信」フォルダは空。

確認できたら、テスト行をシートから削除してください。

---

## 5. 決まった時刻に再送する（オートメーション）

**操作**
1. ショートカットアプリ下の「オートメーション」→「＋」（または「新規オートメーション」）
2. 「時刻」→ `12:00`、繰り返し「毎日」→「すぐに実行」を選び、「次へ」
3. 「受け箱に送る」を選ぶ
4. 同じようにして `21:00` も作る

**こうなればOK**：オートメーションの一覧に2件ある。

任意：「Wi-Fi」→ 自宅のWi-Fiを選ぶ →「すぐに実行」→「受け箱に送る」も作っておくと、帰宅時にも再送されます。

## 6. 仕上げ

手順書1の「移行が終わったら」に従い、スクリプト プロパティの `TOKEN_iPhoneOld` を削除してください。

## 困ったとき

| 症状 | 確認すること |
|---|---|
| 未送信フォルダのファイルが減らない | スプレッドシートの「ログ」シートの最新行の「結果」を見る。`NG` なら辞書の `token` の値が違う。`BADREQ` なら辞書のキー名（小文字の `token` `id` `createdAt` `type` `text`）を確認 |
| 「ログ」シートに何も記録されない | 「URLの内容を取得」のURLと、方法が `POST` になっているかを確認 |
| 未送信フォルダにファイルができない | 手順3の13で「保存先を尋ねる」がオフか、パスが `/未送信/` かを確認 |
| ファイルを開くと中身が `{…}` の形でない | 手順3の11（テキストに辞書を入れる）が抜けていないか確認 |
| 削除のたびに確認が出る | 手順2の5で「削除前に確認」をオフにする |
| 入力欄が出るのが前より遅い | 「入力を要求」が一番上にあるか確認 |
