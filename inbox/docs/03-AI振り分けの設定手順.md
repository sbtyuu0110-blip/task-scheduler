# 手順書3：AI振り分け（段階2）を設定する

所要時間：30分ほど。先に手順書1を終えてください。

> **始める前に**：メモの中身は Anthropic（Claude の会社）のAPIに送られます。仕事のメモを社外のサービスに送ってよいか、会社のルールを確認してからにしてください（APIに送った内容は、標準ではAIの学習に使われません）。

できるようになること
- 「メモ」シートの「未整理」の行を、AIが分類・要約し、手書きなら文字に起こす
- 1つのメモに入っている用件を分けて、「一覧」シートに1行ずつ追加する
- 読めない・判断できないメモは「要確認」にして、理由をH列に書く

---

## 1. Anthropic のAPIキーを用意する

claude.ai の月額プランとは別の、使った分だけ払う仕組みです（目安は月30〜1,000円。モデルによる）。

**操作**
1. パソコンのブラウザで console.anthropic.com を開き、ログイン（アカウントがなければ作成）
2. 「Billing」（支払い）でクレジットを購入する（最低額でかまいません）
3. 「Limits」（上限）で月の上限額を設定する（例：月10ドル）。これを超えると止まるので、使いすぎの心配がなくなります
4. 「API Keys」→「Create Key」→ 名前を `受け箱` にして作成
5. 表示されたキー（`sk-ant-` で始まる長い文字）をコピーする。**この画面を閉じると二度と表示されません**

**こうなればOK**：キーをコピーできた。

> キーは人に見せない・チャットに貼らないでください。漏れたら同じ画面で削除して作り直せます。

---

## 2. キーをスクリプトに登録する

**操作**
1. メモのスプレッドシート →「拡張機能」→「Apps Script」
2. 歯車（プロジェクトの設定）→「スクリプト プロパティ」→「スクリプト プロパティを追加」
3. プロパティ：`ANTHROPIC_API_KEY`、値：手順1でコピーしたキー →「スクリプト プロパティを保存」

**こうなればOK**：一覧に `ANTHROPIC_API_KEY` がある。

---

## 3. 整理のコードを追加する

**操作**
1. 左側の「<>」（エディタ）に戻る
2. 「ファイル」の横の「＋」→「スクリプト」→ 名前を `Organize` にする
3. 中身を全部消して、リポジトリの `inbox/gas/Organize.gs` の中身を貼る → 保存
4. スプレッドシートのタブに戻り、ページを再読み込みする

**こうなればOK**：スプレッドシートのメニューに「受け箱」が出る（出るまで数秒かかることがあります）。

---

## 4. 最初の整理を手動で行う

**操作**
1. 「メモ」シートに、試しのメモが「未整理」で何件かある状態にする（ショートカットで2〜3件送る。例：「牛乳と電池、明日A社に電話」）
2. メニュー「受け箱」→「未整理を今すぐ整理」
3. 初回は「承認が必要です」と出るので、手順書1の手順4と同じように許可する（今回は「外部サービスへの接続」の権限が増えます。Claude APIに送るためです）
4. もう一度「受け箱」→「未整理を今すぐ整理」

**こうなればOK**
- 右下に「○件を整理しました」と出る
- 「メモ」シートの C列（分類）・D列（状態）・H列（AIメモ）が埋まる
- 「一覧」シートができ、用件ごとに行が追加される（「牛乳と電池、明日A社に電話」なら2行。期限に明日の日付）
- 「AIログ」シートに、使ったトークン数と概算費用が記録される

---

## 5. どのモデルを使うか決める（任意・おすすめ）

標準は最も高精度の Opus 5.5 です。安いモデルで十分なら、そちらに切り替えられます。

**操作**
1. 手書きのメモを含め、ふだんのメモが20件ほどたまった頃に行う
2. Apps Script のエディタで、関数の選択欄から `compareOpus` を選んで実行。続けて `compareSonnet`、`compareHaiku` も実行（それぞれ1〜2分）
3. スプレッドシートに「モデル比較」シートができる。同じメモに対する3つのモデルの読み取り・分類が横に並び、一番下に20件分の費用が出る
4. 読み取りと分類が十分なモデルのうち、安いものを選ぶ
5. Opus 5.5 以外にする場合は、スクリプト プロパティに `AI_MODEL` を追加し、値を `claude-sonnet-5-5` または `claude-haiku-5-5` にする

**こうなればOK**：「モデル比較」シートで3つのモデルの結果を見比べられた（比較ではメモシートは変更されません）。

---

## 6. 自動で整理する

**操作**：メニュー「受け箱」→「自動整理をオン（1時間ごと）」または「自動整理をオン（朝7時と夕方18時）」

**こうなればOK**：Apps Script の左側の時計マーク（トリガー）に `organizeInbox` が並んでいる。

- 未整理が0件のときはAIを呼ばないので、1時間ごとにしても費用は増えません
- やめるときは「受け箱」→「自動整理をオフ」

## ふだんの使い方

| こんなとき | すること |
|---|---|
| AIの分類が違う | 「一覧」の分類を直す（AIは「未整理」の行しか触らないので、直した内容は上書きされない） |
| 「要確認」になった | H列の理由を見て、B列のメモを直し、D列を「未整理」に戻す → 次の整理でもう一度処理される |
| テストや誤送信 | D列を「除外」にする（AIは無視する） |
| 用件が終わった | 「一覧」の状態を「完了」にする（ほかに「保留」「不要」） |
| 費用が気になる | 「AIログ」シートの「概算費用（円）」を見る |

## 困ったとき

| 症状 | 確認すること |
|---|---|
| メニュー「受け箱」が出ない | ページを再読み込みする。それでも出なければ、手順3で保存できているか確認 |
| 「AIログ」に「HTTP 401」 | APIキーが違う。手順2の値を確認 |
| 「AIログ」に「HTTP 400」で credit や balance という言葉 | クレジット不足。手順1の2で購入する |
| 「AIログ」に「HTTP 429」「HTTP 529」 | 混雑。自動整理なら次の回に自動でやり直されます |
| 「エラー（次回に再試行）」が続く | 「備考」の文を Claude に貼ってください |
