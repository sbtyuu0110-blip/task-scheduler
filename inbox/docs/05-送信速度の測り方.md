# 手順書5：送信の速さを測る

受け口（Apps Script）が返事をするまでの時間を、ボタン1つで20回測ります。メモのシートには何も書き込みません。

## 測定ページを開く

測定ページは `inbox/tools/measure.html` です。開き方は2通りあります。

- **このリポジトリが main に取り込まれた後**：iPhone の Safari で
  `https://sbtyuu0110-blip.github.io/task-scheduler/inbox/tools/measure.html` を開く
- **パソコンで今すぐ**：リポジトリから `measure.html` をダウンロードし、ダブルクリックでブラウザで開く

## 測る

**操作**
1. 「受け口のURL」と「合言葉」を入れる（合言葉はその端末のブラウザの中だけに保存されます）
2. 回数を20にして「測定開始」
3. 終わったら画面をスクリーンショットで残す
4. Wi-Fi とモバイル回線（Wi-Fi をオフ）で1回ずつ測る

**こうなればOK**：中央値・最悪・1回目・最速が表示され、一覧に「OK-PING」以外の返事が出ていない。

- 「1回目」は、しばらく使っていなかったときの遅さの目安です
- 「NG」が出たら合言葉の間違いです
- 「ログ」シートの「処理ミリ秒」は Google 側でスクリプトが動いた時間です。測定ページの時間との差が、通信と Google の受付にかかった時間です

**Claude に送ってほしいもの**：Wi-Fi とモバイル回線、それぞれのスクリーンショット。
