サービス内容（本文）

出品画面の「サービス内容」欄にそのまま貼ります。

本文
毎月とどく請求書のPDFを、Excel（またはスプレッドシート）へ
自動で転記する仕組みをお作りします。


■ こんな方へ

・毎月、請求書PDFを開いてExcelに手入力している
・1回15分〜30分だが、毎月なので地味に負担
・つい後回しにして、請求書が溜まりがち
・入力ミスがないか、毎回目視で確認している

同じ発行元から、毎月同じ形式で届く請求書が対象です。


■ お届けするもの

・請求書PDFを読み取り、必要な項目だけを抜き出す仕組み
・Excelの台帳に追記、または
　スプレッドシートへそのまま貼り付けられる形での出力
・金額の検算機能（下記）
・操作手順書（3ステップ程度の簡単なもの）

作業はボタン1つ、または1行のコマンドで完了します。


■ 料金について（枚数は関係ありません）

9,800円は「請求書1枚あたり」ではなく、
「仕組みを1つお作りする費用」です。

一度お作りすれば、
・同じ書式の請求書は、何枚でも処理できます
・毎月くり返しお使いいただけます
・追加の費用はかかりません

追加費用がかかるのは、
別の発行元・別の書式を増やす場合だけです（1つにつき追加）。


■ このサービスの中心は「転記」ではなく「検算」です

自動化でこわいのは、動かなくなることではありません。
動いているように見えて、静かに間違え続けることです。

実際にこういう例があります。
ある会社では請求書の取込ツールが動いていましたが、
請求書の書式が変わったことに気づかないまま、
明細が取れず合計金額だけが入る状態になり、
決算で数字が合わないと分かるまで運用が続いていました。

そこで、お作りするものには必ず検算を入れます。

・各行の 数量 × 単価 と 金額 が一致するか
・明細の合計 と 小計 が一致するか
・小計 ＋ 消費税 と 合計金額 が一致するか

1つでも合わなければ、Excelには書き込みません。
そして「この行が読み取れませんでした」と、
具体的な行の名前を出して止まります。

例：
　検算不一致 — 明細合計=31,140 だが 小計=30,000（差額 +1,140）
　読み取れなかった行があります： 前月調整額 -1,140

差額まで出しますので、どこがおかしいのかをご自身で確認できます。

黙って1行落ちた表よりも、止まった方が安全だと考えています。


■ 請求書の書式が毎月少し変わる場合

実際の請求書は、項目が増えたり位置が動いたりします。
そこも想定して作ります。

・新しい項目が増えた／行数が変わった
　→ そのまま処理できます

・行の作りが違う項目が来た（数量や単価のない調整額など）
　→ 止めて、その行をお知らせします

止まった月は、その分だけ手で入れていただくか、
ご連絡いただければ対応を追加します。


■ お受けできないこと（先にお伝えします）

・スキャンした紙・写真・手書きの請求書
　画像から文字を読む処理は100%にできず、誤読を検算できないためです
　発行元からデータ形式のPDFを受け取れる場合はご相談ください

・発行元ごとに書式が違う請求書をまとめて処理すること
　（1つの発行元・1つの書式が対象です）

・会計ソフトへの直接連携

・転記結果そのものの正当性の保証
　（検算はしますが、最終確認はお客様にお願いしています）


■ 購入前に、1枚だけ無料でお試しいただけます

「うちの請求書で本当に動くのか」が一番の不安だと思います。

購入前のメッセージで、請求書PDFを1枚お送りください。
（金額の部分は塗りつぶしていただいて構いません）

こちらで読み取りを試し、
・そもそも対応できる形式か
・どの項目が取り出せるか
を、実際の出力結果でお返しします。

対応できない形式だった場合は、その時点でお断りします。
無理にお受けして納品できない方が、お互いに損だと考えています。


■ 進め方

1. 購入前のメッセージで、請求書PDFを1枚拝見します（無料）
2. 抜き出す項目の一覧をこちらから提示し、ご確認いただきます
3. ご購入後、作成します
4. 実際の1枚で動作をご確認いただき、操作手順書をお渡しします


■ ご相談のときに教えていただきたいこと

・請求書PDF（1〜3枚。金額は塗りつぶしていただいて構いません）
・転記先のExcel／スプレッドシート（列の並びが分かるもの）
・いま、その作業に毎月どのくらい時間がかかっているか
・請求書は毎月何枚ほど届くか
・発行元は1社ですか、複数ですか

これが分かれば、対応できるかどうかを具体的にお答えできます。


■ 使用する技術

Python / Google Apps Script / Excelマクロ
ご希望の運用に合わせて選びます。指定がなければこちらで判断します。

作業完了後に削除します。
取引先名・金額を第三者に開示することはありません。
動作確認は、可能な限りダミーデータで行います。
