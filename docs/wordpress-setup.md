# WordPress 立ち上げ手順（詳細版）

サーバー契約からASP審査に出せる状態まで。所要 2〜3時間。

---

## 1. ConoHa WING の契約

### 申し込み画面での選択

| 項目 | 選ぶ値 | 理由 |
|---|---|---|
| 料金タイプ | **WINGパック** | 通常料金だとドメイン無料特典が付かない |
| 契約期間 | **12ヶ月** | 3ヶ月は割高、36ヶ月は成果が読めない段階では長すぎる |
| プラン | **ベーシック** | 個人ブログには十分。上位プランは不要 |

### WordPressかんたんセットアップ

「利用する」を選ぶ。ここでサーバー・ドメイン・WordPress・SSLが一括で設定される。

| 項目 | 入力内容 |
|---|---|
| セットアップ方法 | 新規インストール |
| 独自ドメイン | `dandori-tousan.com` |
| 作成サイト名 | ダンドリ父さん |
| WordPressユーザー名 | **`admin` 以外にする**（総当たり攻撃の的になる） |
| WordPressパスワード | 強固なもの。使い回さない |
| WordPressテーマ | **Cocoon**（この画面で選べる） |

### ドメインの注意

- **`.com` を選ぶ。** `.xyz` などの格安ドメインは信頼性・スパム判定の面で不利
- 取得できるか画面上で検索される。埋まっていた場合の代案：`dandori-tosan.com` / `shikumi-ikuji.com`
- **ドメインは後から変えるとSEO資産がリセットされる。** ここだけは確定前に考える

### サイト名の根拠

「ダンドリ父さん」はコンセプト（根性ではなく仕組みで回す）から逆算した。「仕組み」は育児ジャンルでは硬いため、日本語の言い換えとして「段取り」を採用している。

**重複チェック済み**：同名のブログ・サイトは存在しない。ただし漫画『ダンドリくん』（泉昌之／1990-91）があり、「ダンドリ＋人」は既視感のある命名パターン。ジャンルが異なるため実害はない。

**「パパ」ではなく「父さん」を選んだ理由**：既存の父親育児ブログはパパやる／パパ部／パパの日々／パパ育児ブログと、ほぼ全てが「パパ＋何か」。同じ形で参入すると埋もれる。加えて「ダンドリ」という誰も使っていない軸が入るため、名前だけで区別がつく。

代案として検討し、落としたもの：

- `shikumi-ikuji.com`（仕組み育児）— 硬すぎる
- `mawaru-ie.com`（回る家）— 何のサイトか伝わらない

### 契約後

お客様情報 → SMS/電話認証 → 支払い情報で完了。

**無料独自SSLの有効化には30分〜数時間かかることがある。** すぐ `https://` にならなくても慌てない。

## 2. WordPress 初期設定

### パーマリンク設定（最優先）

**これを最初にやる。後から変えると全記事のURLが変わり、SEO評価がリセットされる。**

`設定 → パーマリンク → カスタム構造` に以下を入力：

```
/%postname%/
```

これで `dandori-tousan.com/timeline/` のようなURLになる。

**注意**：日本語タイトルのままだとURLが日本語（エンコードされて長大な文字列）になる。記事ごとに**英数字のスラッグを手動で設定する**こと。

- 例：「共働きの平日タイムラインを公開」→ スラッグ `weekday-timeline`

### 一般設定

`設定 → 一般`

| 項目 | 値 |
|---|---|
| サイトのタイトル | ダンドリ父さん |
| キャッチフレーズ | 共働き2児を回すための実装記録 |
| WordPressアドレス / サイトアドレス | `https://` で始まっているか確認 |

### 初期状態の掃除

- 投稿「Hello world!」を削除
- 固定ページ「サンプルページ」を削除
- プラグイン「Hello Dolly」を削除

### ディスカッション設定

`設定 → ディスカッション` でコメントを**オフ**にしてよい。スパム対応の手間に対して、初期のメリットがない。

---

## 3. プラグイン（最小構成）

入れすぎると重くなる。最初はこの3つだけ。

| プラグイン | 用途 |
|---|---|
| **SEO SIMPLE PACK** | メタタイトル・メタディスクリプションの設定 |
| **Contact Form 7** | お問い合わせフォーム（ASP審査に必要） |
| **WP Multibyte Patch** | 日本語環境の不具合対策 |

---

## 4. 必須ページの作成

**ASP審査で最も多い落選理由がプライバシーポリシーの不在。** 記事より先に作る。

いずれも `固定ページ` として作成する。

| ページ | 原稿 |
|---|---|
| プライバシーポリシー | `docs/wordpress-pages/privacy-policy.md` |
| 運営者情報 | `docs/wordpress-pages/about.md` |
| お問い合わせ | Contact Form 7 のショートコードを貼るだけ |

作成後、フッターメニューに3ページとも表示させる（`外観 → メニュー`）。審査時に見つけられないと意味がない。

---

## 5. 計測設定

後回しにすると初期データが取れず、後から検証できなくなる。

### Google Search Console

1. プロパティを追加（URLプレフィックス方式が簡単）
2. 所有権の確認 → HTMLタグを取得
3. `Cocoon設定 → アクセス解析・認証` の「ヘッド用コード」に貼る

### Google Analytics

1. GA4プロパティを作成
2. 測定ID（`G-XXXXXXXXXX`）を取得
3. `Cocoon設定 → アクセス解析・認証` の「GA4測定ID」欄に貼る

---

## 6. Cocoon の最低限の設定

デザインの作り込みは不要。以下だけ触る。

- `Cocoon設定 → 全体` → サイトキーカラーを決める（1色でよい）
- `Cocoon設定 → SEO` → 「日付を表示」をオン（育児情報は鮮度が信頼に直結する）
- `Cocoon設定 → 広告` → **今は触らない**。アドセンスは狙わない方針のため

---

## やらないこと

初心者が最も時間を溶かす作業。すべて後回しでよい。**記事が先。**

- デザインの作り込み
- ロゴ制作
- 有料テーマの購入（SWELL等）
- プラグインの大量導入
- カテゴリの作り込み（記事が増えてから整理すればよい）
